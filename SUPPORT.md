# Support

SkipEcho is experimental and maintained on a best-effort basis. There is no guaranteed response time.

## Where to go

Use [New issue](https://github.com/revo1290/skip-echo/issues/new/choose) and pick the form that fits:

| You want to | Form |
| --- | --- |
| Ask how SkipEcho works or how to use it | Question |
| Report that a condition, correction, complete artifact, or other essential information was left out | Missing necessary information |
| Report an unchanged explanation that was repeated | Unnecessary repetition |
| Report that the plugin did not load or did not inject its policy | Activation or installation issue |
| Suggest a change | Feature request |
| Report a security problem | Do not post details in a public issue. Read [SECURITY](SECURITY.md) first |

## Before you file

- Read [compatibility](docs/compatibility.md). Most environments are untested, and it records what has been observed. A formal list of supported clients is still open (#10); until then that page is the record. Reports from untested environments are still useful.
- Include the OS, Node.js version, Claude Code version, model, plugin version, other styles you use, and how you installed SkipEcho.
- Share only synthetic or redacted examples. Never include tokens, private code, or raw personal transcripts.
